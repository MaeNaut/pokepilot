# Tutorial captures

Actual local PokePilot UI captures, using a Singles Garchomp sample and a
Gholdengo opponent. Analysis screenshots are example outputs, not live requests
made by the tutorial. Pokemon assets retain the app's existing attribution.

Files: `builder.jpg`, `calculator.jpg`, `copilot.jpg`, `help.jpg`.

All users see English, light-theme, Singles, desktop captures.
The analysis panel remains dark because the app uses an inverted panel theme.
Native crops: builder 988x506, calculator 1384x811, copilot 480x440,
help 1050x502. JPEG is the browser capture backend's native output.
Images use contain, never cover, and link to the full-size original.

When refreshing these assets, use UI controls to set the language, theme and
Singles format. Wait until drawers and mobile page transitions have settled,
then crop the editor, damage results, or analysis panel. Check the images for
clipped controls, overlays and missing sprites before replacing them. Do not
capture account details or user teams. Keep these four assets in sync.
