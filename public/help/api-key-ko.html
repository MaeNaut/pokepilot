API 키 발급 가이드

개인 OpenAI API 키를 발급하고 PokePilot에 등록하는 순서입니다. 키 발급은 OpenAI에서, 등록은 PokePilot에서 진행합니다.

1. 시작 전 확인

AI 분석에는 PokePilot 로그인과 개인 OpenAI API 키가 필요합니다. 팀 빌더와 대미지 계산기는 키 없이 사용할 수 있습니다.

분석 비용은 본인의 OpenAI 계정에 청구됩니다. ChatGPT 구독료와 API 요금은 별개입니다. 키 발급만으로 PokePilot 분석이 실행되지는 않습니다.

키는 비밀번호처럼 취급합니다. 댓글, GitHub Issues, 채팅이나 스크린샷에 키를 노출하지 않습니다. 이 가이드에는 키를 입력하지 않습니다.

2. 계정과 결제 준비

  1. OpenAI Platform에 로그인합니다.
  2. 사용할 프로젝트를 선택합니다. 개인 사용 전용 프로젝트나 키 이름으로 용도를 구분하면 관리하기 편합니다.
  3. Billing에서 계정에 필요한 결제 설정과 사용 가능한 잔액을 확인합니다. 결제 금액과 자동 충전 조건은 직접 확인한 뒤 진행합니다.
  4. Usage에서 사용량을 확인합니다. 예산 알림을 설정하더라도 자동으로 모든 지출이 차단된다고 가정하지 않습니다.

카드 정보는 OpenAI의 결제 화면에서만 입력합니다. PokePilot에는 카드 정보를 입력하지 않습니다.

3. 키 발급과 권한

  1. API keys에서 Create new secret key를 선택합니다.
  2. 개인 사용이면 Owned by: You를 선택하고, 이름은 pokepilot-personal처럼 구분하기 쉽게 정합니다.
  3. Permissions: Restricted를 선택합니다. Model capabilities를 펼쳐 Responses (/v1/responses): Write를 허용하고, 사용하지 않는 항목은 None으로 둡니다.
  4. 만료일을 확인한 다음 키를 생성합니다. 만료일을 설정하면 만료 전에 새 키를 등록해야 합니다.
  5. 표시된 키를 복사해 다음 단계에서 등록합니다. 다시 확인하지 못할 수 있으므로 보관이 필요하면 비밀번호 관리자를 사용합니다.

화면 이름이나 권한 구성은 OpenAI 업데이트로 달라질 수 있습니다. 항목이 다르면 무작정 All로 넓히지 말고 공식 권한 안내를 확인합니다.

4. PokePilot에 등록

  1. PokePilot을 열고 오른쪽 위 프로필 버튼에서 로그인합니다.
  2. 계정 메뉴의 개인 API 키 입력란에 발급한 키를 붙여넣고 등록합니다.
  3. 키 등록 상태와 삭제 버튼이 나타나는지 확인합니다. 저장된 키 값은 다시 표시하지 않습니다.
  4. 팀이나 포켓몬을 준비하고 모델을 선택합니다. 분석 버튼을 누르면 예상 시간과 비용을 확인할 수 있습니다. 최종 확인 후 분석이 실행됩니다.

예상 비용은 실제 청구액과 다를 수 있습니다. 등록 완료는 모든 모델의 호출 성공을 보장하지 않으며, OpenAI 계정의 모델 접근 권한과 잔액에 따라 분석이 실패할 수 있습니다.

키는 HTTPS로 PokePilot 서버에 전송되어 암호화 저장되며, 분석 요청 시 서버에서 복호화해 OpenAI 호출에 사용됩니다. 자세한 내용은 개인정보 안내를 확인합니다.

5. 문제 해결과 키 관리

인증 또는 권한 오류가 발생합니다

키가 만료·폐기되지 않았는지 확인합니다. Restricted 설정의 Responses Write 권한과 프로젝트의 모델 접근 권한을 확인합니다. 키를 잘못 복사했다면 등록된 키를 삭제하고 다시 등록합니다.

잔액 부족 또는 요청 제한이 표시됩니다

OpenAI Billing과 Usage에서 잔액·사용 한도를 확인합니다. 요청 속도 제한이면 안내에 따라 기다린 뒤 다시 시도합니다. PokePilot에 자체 일일 분석 한도가 없더라도 OpenAI의 제한은 적용됩니다.

키를 바꾸거나 사용을 중단하고 싶습니다

PokePilot 계정 메뉴에서 등록된 키를 삭제한 뒤 새 키를 등록합니다. PokePilot에서 삭제해도 OpenAI의 원본 키는 폐기되지 않습니다. 완전히 사용을 중단하려면 OpenAI API keys에서도 해당 키를 삭제합니다.

키가 노출된 것 같습니다

OpenAI API keys에서 해당 키를 즉시 폐기하고 사용 내역을 확인합니다. 새 키를 발급해 다시 등록합니다. 문의할 때는 키와 개인정보를 가리고 오류 문구만 전달합니다.
