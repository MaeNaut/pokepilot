API key setup guide

Create a personal OpenAI API key, then register it with PokePilot. Key creation happens on OpenAI; registration happens on PokePilot.

1. Before you start

AI analysis requires a PokePilot account and a personal OpenAI API key. The team builder and damage calculator work without a key.

OpenAI charges your account for analysis. API billing is separate from a ChatGPT subscription. Creating a key does not start a PokePilot analysis.

Treat your key like a password. Never include it in comments, GitHub Issues, chats, or screenshots. Do not enter a key on this guide page.

2. Account and billing

  1. Sign in to OpenAI Platform.
  2. Select a project. A personal-use project or clearly named key helps separate usage.
  3. Check Billing for the payment setup and balance your account needs. Review amounts and automatic recharge settings before proceeding.
  4. Monitor Usage. Do not assume a budget alert automatically blocks all further spending.

Enter payment details only on OpenAI's billing page, never in PokePilot.

3. Create a restricted key

  1. Open API keys and select Create new secret key.
  2. For personal use, select Owned by: You. Use a name such as pokepilot-personal.
  3. Select Permissions: Restricted. Expand Model capabilities, allow Responses (/v1/responses): Write, and leave unused permissions at None.
  4. Review expiration, then create the key. If you set an expiry date, replace the key before it expires.
  5. Copy the key for the next step. You may not be able to reveal it again; use a password manager if you need to retain it.

OpenAI may change screen labels and permission controls. If they differ, consult the official permission guide rather than enabling All by default.

4. Register with PokePilot

  1. Open PokePilot and sign in through the profile button at the top right.
  2. Paste your key into the personal API key field in the account menu and save it.
  3. Check for the saved-key status and delete button. The stored key is not shown again.
  4. Prepare your Pokemon or team and select a model. Press the analysis button to review estimated time and cost. Analysis starts after final confirmation.

Estimates may differ from actual charges. Saving a key does not guarantee access to every model: OpenAI model access and account balance still apply.

Your key is sent to the PokePilot server over HTTPS, stored encrypted, and decrypted on the server to call OpenAI for analysis. Read the privacy notice for details.

5. Troubleshooting and key care

Authentication or permission error

Check that the key is not expired or revoked. Verify Responses Write permission and the project's model access. If you copied the wrong key, remove it from PokePilot and register it again.

Insufficient balance or rate limit

Check OpenAI Billing and Usage for balance and usage limits. For rate limits, wait as instructed before retrying. OpenAI limits still apply even though PokePilot has no daily analysis quota.

Replace a key or stop using it

Delete the registered key from the PokePilot account menu, then register a replacement. Removing it from PokePilot does not revoke the original OpenAI key. To stop its use everywhere, delete it on OpenAI's API keys page too.

A key may have leaked

Revoke it immediately on OpenAI's API keys page and review usage. Create and register a replacement. Remove keys and personal information from error reports and screenshots.
