# Security Policy

## Reporting a Vulnerability

When it is available, please use GitHub's private vulnerability reporting flow:

https://github.com/MaeNaut/pokepilot/security/advisories/new

Do not include API keys, private team data, personal information, or working
exploit details in a public issue. While private reporting is unavailable, open
a minimal public issue asking for a private contact channel without disclosing
the sensitive details.

General bugs and product feedback belong in GitHub Issues:

https://github.com/MaeNaut/pokepilot/issues

## Scope

The supported version is the current production deployment at
https://pokepilot-ai.vercel.app and the latest commit on `main`.
